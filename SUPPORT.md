# Get help

Use [Q&A Discussions](https://github.com/logelog/shipit-seo-plugin/discussions/categories/q-a)
for setup questions and [Ideas](https://github.com/logelog/shipit-seo-plugin/discussions/categories/ideas)
for suggestions. Include the plugin, EmDash/admin, Node and database versions,
the command or action you tried, and the result.

For a reproducible bug, use the [bug report form](https://github.com/logelog/shipit-seo-plugin/issues/new?template=bug_report.yml).
Share a small synthetic example and relevant, redacted output. Keep passwords,
tokens, database files, customer content and private URLs out of public posts.

Report security concerns privately as described in [SECURITY.md](SECURITY.md).
See [CONTRIBUTING.md](CONTRIBUTING.md) to propose a fix or translation.

This beta has no guaranteed response time. Its package README describes the
tested platforms and current limits.
